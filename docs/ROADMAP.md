# Architecture Roadmap

## Phase 1: Foundation
- Establish documentation.
- Add shared constants and config structure.
- Add feature-based source layout.
- Add middleware, exceptions, responses, repositories, and services foundations.

## Phase 2: Platform Infrastructure
- Add authentication and tenant context.
- Add persistence adapter.
- Add migration tooling.
- Add observability, request logging, and health checks.

## Phase 3: Business Features
- Implement ERP modules as isolated features.
- Add background jobs and notification workers.
- Add file scanning and retention policies.

## Phase 4: Enterprise Readiness
- Add SSO.
- Add advanced permissions.
- Add data export/import.
- Add compliance reporting.
